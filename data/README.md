A short README and attribution for the WDI CSVs.

Source: World Bank, World Development Indicators (pulled from the datasets/world-development-indicators GitHub mirror). Data license: CC BY 4.0.

Indicator codes -> filenames

- sh.sta.diab.zs -> data/diabetes_prevalence.csv (Diabetes prevalence, % of adults 20-79)
- ms.mil.xpnd.gd.zs -> data/military_expenditure_pct_gdp.csv (Military expenditure, % of GDP)
- sh.med.beds.zs -> data/hospital_beds_per_1000.csv (Hospital beds, per 1,000 people)
- ny.gdp.pcap.cd -> data/gdp_per_capita.csv (GDP per capita, current US$)
- sp.dyn.le00.in -> data/life_expectancy.csv (Life expectancy at birth, years)
- sh.dth.ncom.zs -> data/ncd_deaths_pct.csv (Deaths due to noncommunicable diseases, % of total deaths)
